# Dhvanit Vaghela — Portfolio

A responsive one-page portfolio built with Next.js App Router.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run:

```bash
npm install
npm run dev
```

4. Visit http://localhost:3000

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. Sign in to Vercel and choose **Add New → Project**.
3. Import the repository. Vercel should detect Next.js automatically.
4. Keep the default build settings and click **Deploy**.

## Before publishing

- Confirm that each project link and its public presentation accurately reflects your contribution and permission to showcase it.
- Replace the visual project previews with real screenshots/mockups if you have permission and suitable assets.
- Update the metadata URL in `app/layout.tsx` after choosing your final domain.
- The phone, email and Instagram links are set to the details provided.
